# 打包说明（一次配置，以后直接打包）

## 第一步：只做一次——创建并填写 env.json

1. **复制示例文件**  
   在「终端」里进入本项目的 `app` 目录，执行：
   ```bash
   cp env.json.example env.json
   ```
   完成后，`app` 目录下会多出一个 `env.json` 文件。

2. **用记事本 / VS Code / Cursor 打开 `env.json`**，按下面说明把占位内容改成你自己的值（不要改键名，只改引号里的值）：

   | 键名 | 填什么 | 从哪里找 |
   |------|--------|----------|
   | **SUPABASE_URL** | 你的 Supabase 项目地址 | 打开 [Supabase](https://supabase.com/dashboard) → 你的项目 → **Settings** → **API** → **Project URL**，整段复制 |
   | **SUPABASE_ANON_KEY** | 你的 Supabase 匿名密钥 | 同上页 → **Project API keys** → **anon public**，复制 |
   | **PGYER_APP_KEY** | 蒲公英应用 Key（要用更新功能再填） | 打开 [蒲公英](https://www.pgyer.com) → 上传过 APK 的应用 → **应用管理** → 应用信息里的 **App Key** |
   | **PGYER_API_KEY** | 蒲公英 API 密钥（要用更新功能再填） | 蒲公英网站 → 右上角头像 → **API 信息** → 复制 **API Key** |

3. **保存** `env.json`。  
   不需要蒲公英更新时，`PGYER_APP_KEY` 和 `PGYER_API_KEY` 可以保持 `""`。

**示例**（请替换成你自己的值）：
```json
{
  "SUPABASE_URL": "https://abcdefghijk.supabase.co",
  "SUPABASE_ANON_KEY": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "PGYER_APP_KEY": "abc123xyz",
  "PGYER_API_KEY": "your_pgyer_api_key"
}
```

> `env.json` 已加入 .gitignore，不会被提交到 git，密钥只在你本机。

---

## 第二步：USB 调试运行（实时看效果）

用数据线连接手机和电脑，手机开启 **开发者选项** 和 **USB 调试** 后，在 **app** 目录执行：

```bash
./scripts/run_with_env.sh
```

统一入口会自动优先选择已连接 Android 真机，没有真机时选择 Chrome；追加 `menu` 可反复切换。Android 使用 `env.json` 配置，Web 只使用其中公开的 Supabase 配置，不包含蒲公英密钥。
若未配置 `env.json`，脚本会提示先完成第一步。

---

## 第三步：以后每次打包

在 **app** 目录下执行一条命令即可（不用再传 URL、key 等参数）：

```bash
./scripts/build_release.sh
```

生成的 APK 在：`app/build/app/outputs/flutter-apk/app-release.apk`。

---

## 小结

- **第一次**：复制 `env.json.example` → 得到 `env.json` → 打开并填好 Supabase（和可选蒲公英）的 4 个值 → 保存。
- **USB 调试**：在 `app` 目录运行 `./scripts/run_with_env.sh`，用 `env.json` 配置实时跑在真机上。
- **打包发布**：在 `app` 目录运行 `./scripts/build_release.sh`，Supabase 和蒲公英都会用 `env.json` 里的值。
