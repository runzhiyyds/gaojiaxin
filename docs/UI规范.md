# 顺顺&佳猫的爱情故事 - UI 规范

## 风格与情感化

- **调性**：温暖、亲密但不幼稚；简洁清晰，避免信息过载。
- **色彩**：主色暖粉/珊瑚色 + 深灰或深紫；辅色用于强调（兑换、正反馈）；背景浅色或浅渐变；支持深色模式。
- **字体**：无衬线体，标题/正文/辅助层级分明；数字（心意值、分值）可加粗或等宽数字。
- **图标**：线性图标或轻量插画，统一风格，增强情侣专属感。
- **首屏**：可自定义情侣照片作为背景；应用名「顺顺&佳猫的爱情故事」；副标题「我们的爱情心意值」。

## 关键界面要点

- **启动页**：应用名 + 副标题或插图，品牌一致。
- **首页**：突出当前周期总心意值与「记一笔」；最近记录 3～5 条。
- **心意项目**：列表可拖拽排序；图标、名称、单次心意值；详情可编辑名称/图标/心意值/周期类型/启用。
- **周期视图**：日/周/月 Tab；列表或简单图表，双方得分与合计。
- **爱情旅程**：纵向时间轴，左侧我记下的、右侧 TA 记下的；顶部时间范围筛选；心意值以一位小数展示，可带爱的维度标签。
- **心意商城**：卡片列表（图+名称+所需心意值）；详情大图+说明+兑换按钮；心意值不足时按钮置灰并提示。
- **我的**：双人头像或单人头像+绑定状态；设置分组（账号与绑定、周期与通知、关于与热更新）。
- **记一笔**：普通模式为小额/中额/大额三档随机；霸总模式为自由输入；心意值支持一位小数。

## 组件与一致性

- **按钮**：主按钮、次按钮、危险操作统一样式。
- **列表项**：左图/左图标 + 标题 + 副标题/右文案。
- **表单**：输入框、选择器、开关统一。
- **反馈**：弹窗与 Toast 统一（成功/失败/提示）。

## 应用外显

- **应用名**：顺顺&佳猫的爱情故事
- **副标题**：我们的爱情心意值（启动页、关于页等）
- **APP Icon**：需单独设计，与品牌一致。
