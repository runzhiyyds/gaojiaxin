# 顺顺&佳猫的爱情故事 - 产品说明

## 产品定位

面向情侣的「爱情心意值」应用：通过心意值记录与激励彼此的付出与互动，在心意商城中兑换约定奖励，让相处更有仪式感。

## 功能列表

| 模块 | 功能 |
|------|------|
| 账号 | 邮箱+密码注册/登录；本地会话恢复；网络错误提示与重试 |
| 绑定 | 邀请码/绑定链接；双方绑定后形成情侣空间，数据按空间隔离 |
| 心意项目 | 预置项（做家务、准备惊喜、陪伴时长等）+ 自定义项；支持名称、图标、单次心意值、周期类型、排序、启用 |
| 心意记录 | 记一笔（选项目、心意值、时间）；记录列表与筛选；按日/周/月周期统计 |
| 心意商城 | 商品/权益维护（名称、所需心意值、库存、图片）；兑换与兑换记录；可配置双方或仅一方可兑换 |
| 系统 | 周期起始日配置；通知开关；关于与热更新 |

## 页面树

```
├── 启动/闪屏
├── 登录（邮箱 + 密码）
├── 绑定（生成邀请码 / 输入邀请码）
├── 主框架（底部 Tab）
│   ├── 首页：当前周期总心意值、快捷记一笔、最近记录
│   ├── 心意：心意项目列表、项目编辑、记录流水、周期视图（日/周/月）
│   ├── 爱情旅程：时间轴展示双方记下的心意事件，左我右 TA，支持时间筛选与分页
│   ├── 心意商城：商品列表、商品详情与兑换、兑换记录
│   └── 我的：情侣信息、设置、退出登录
```

## 关键流程

- **登录 → 首页 → 绑定**：成功登录后先进入首页，后台同步情侣空间；未绑定时从提示或「我的」进入绑定流程。查询失败提供重试，不将网络错误判定为未绑定。
- **记一笔**：选心意项目；普通模式选小额/中额/大额由系统随机心意值（一位小数），霸总模式可自由输入；确认后写入记录并刷新周期统计。
- **兑换**：选商品 → 确认心意值足够 → 兑换 → 扣减心意值、写兑换记录。

## 数据模型概要

- **用户**：邮箱、昵称、头像、伴侣绑定关系。
- **情侣空间**：couple_space_id，下挂心意项目、记录、商城。
- **心意项目**：空间内；预置/自定义、名称、图标、心意值、周期类型、排序、启用。
- **心意记录**：用户、项目、心意值、时间、周期。
- **商城商品**：名称、所需心意值、库存、图片。
- **兑换记录**：用户、商品、时间、扣减心意值。
